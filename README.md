#  📝 SISTEMA DE LOGIN VALIDADO COM NODE/ SQL 

* Fiz um sistema na linguagem de programação Javascript utilizando conceitos de DOM, Arrays, Functions etc... 
* O mais interessante desse projeto foi o estudo em Node.JS ligando o Backend ao Frontend
* O SQL foi o objetivo principal, guardar dados reais dentro de uma estrutura de banco de dados.
* O sistema de segurança de senhas era guardado por HASH

---

# COMO RODAR O PROJETO ?

Primeiramente faça isso: 
* Tenha instalado o VSCODE ou outro editor
* Instale o MySQL
* Instale o Node.js
* Instale o Live Server / Navegador


```
bash git clone https://github.com/MatheusViniciusDiasAlves/Login_System-
```

```
cd "Tela login"
```

```
cd backend
```
```
npm install
node server.js
```
